# Services

Go microservices live here.

Each service owns its own domain logic, database access, migrations, authorization checks, audit behavior, and tests. Services must not query another service database.

MVP services:

- `api-gateway`
- `identity-service`
- `school-core-service`
- `admission-service`
- `academic-service`
- `finance-service`
- `communication-service`
- `reporting-service`
